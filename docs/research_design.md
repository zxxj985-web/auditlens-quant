# AuditLens Quant — 研究设计

## 1. 研究问题

上市公司的现金流质量、应计利润、偿债压力和营运资本异常，能否在不使用未来信息的前提下，成为 A 股多头组合的有效风险过滤层？

项目不预设因子一定产生超额收益。核心目标是检验：排除财务质量—信用风险评分最差的公司后，组合的最大回撤、波动率和风险调整后收益是否改善。

## 2. 与个人经历的联系

- 审计经验：利润与现金流差异、应收账款、存货和异常会计项目。
- 对公银行经验：杠杆、偿债覆盖、流动性和企业信用风险。
- 金融科技训练：Python 数据管道、可复现因子研究和回测验证。

项目只使用公开市场数据，不使用或推断任何审计、银行内部资料。

## 3. 首版研究范围

- 市场：A 股。
- 股票池：27 家跨行业大型非金融企业的静态演示股票池。
- 暂不纳入银行和保险：金融机构报表结构不同，不能直接套用一般企业的存货、应收账款和流动比率框架。
- 行情：复权日收盘价。
- 财务频率：年度报表。
- 调仓：月末形成信号，下一个月持有。
- 基准：同股票池等权组合与沪深 300 ETF（`510300.SS`）代理。

静态股票池存在幸存者偏差，因此首版结果仅属于研究原型，不作为实盘收益证明。第二阶段应接入历史指数成分股或完整退市样本。

## 4. 时间对齐与反泄漏规则

每份财务报表必须绑定可获得日期：

1. 优先使用公开的财报/业绩发布日期；
2. 若发布日期缺失，则对年度期末日增加 120 天的保守滞后；
3. 某个月末只能使用发布日期不晚于该月末的最新报表；
4. 月末形成的权重仅用于下一个月收益；
5. 测试会自动检查 `publication_date <= rebalance_date`。

## 5. 因子

所有因子统一为“数值越高，财务质量越好”。

| 因子 | 公式 | 解释 |
|---|---|---|
| 现金流含金量 | CFO / \|净利润\| | 利润是否由经营现金流支持 |
| 应计质量 | -(净利润-CFO) / 平均资产 | 应计利润越低通常越稳健 |
| 自由现金流 | FCF / 平均资产 | 企业自我造血能力 |
| 净利率 | 净利润 / 营收 | 盈利能力 |
| 低杠杆 | -总负债 / 总资产 | 资产负债压力 |
| 利息保障 | EBIT / \|利息费用\| | 债务利息覆盖能力 |
| 现金债务覆盖 | 现金及短期投资 / 总债务 | 流动性缓冲 |
| 应收效率 | -应收账款 / 营收 | 回款与收入质量 |
| 存货效率 | -存货 / 营收 | 存货积压风险 |

每月横截面对因子进行 5%/95% 去极值、标准化，并在行业样本数足够时进行行业中性化。综合分数按配置权重加权，只对至少具备五个有效因子的公司评分。

## 6. 组合与成本

- 风险过滤组合：排除综合分数最低的 20%，其余股票等权。
- 股票池基准：所有当月可评分公司等权。
- 交易成本：按单边换手率收取 10 bps，可在配置中修改。
- 不做空、不使用杠杆，贴近普通实习项目的可解释性和可执行性。

## 7. 评价指标

- 年化收益、年化波动率、Sharpe、最大回撤、Calmar、月度胜率；
- 月均换手率、组合持仓数量；
- 综合评分及单因子与下一月收益的横截面 Rank IC；
- 2024 年起作为样本外区间，单独报告指标。

## 8. 不可夸大的内容

- 回测不等于未来收益；
- 当前静态股票池不能消除幸存者偏差；
- 免费数据源可能发生历史字段修订；
- 财务发布日期回退规则是保守近似，报告会披露其占比；
- 项目结论必须由实际运行结果决定，不预写“有效”或“跑赢”。
